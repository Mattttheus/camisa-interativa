# Modelos 3D

Coloque aqui um arquivo `camisa.glb` para a página abrir com ele (botão **.glb** em "Modelo 3D").

A página reconhece as peças pelo nome do objeto ou do material:

| Nome contém | Tratamento |
| --- | --- |
| `botao`, `button` | recebe o material de botão escolhido |
| `gola_italiano`, `gola_ingles`, `gola_cutaway`, `gola_clube`, `gola_buttondown`, `gola_padre` | aparece só com a gola escolhida |
| `punho_simples`, `punho_chanfrado`, `punho_redondo`, `punho_barril`, `punho_frances` | aparece só com o punho escolhido |
| `bolso` | aparece só com o bolso ligado |
| `abotoadura` | aparece só com o punho francês |
| `manequim`, `keep` | fica como está |
| qualquer outro | recebe tecido, cor e padronagem |

O modelo deve estar em pé (eixo Y para cima) e de frente para +Z.
